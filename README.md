# The Internet UI Automation Tests

Automation testing project for the-internet.herokuapp.com using Selenium WebDriver.

## Tech Stack
- Java
- Selenium WebDriver
- Maven
- TestNG

## Features
- UI automated tests
- Web element interaction
- Assertions and validations
- Form testing
- Browser automation

## Tested Functionality
- Login form
- Checkboxes
- Dropdowns
- Alerts
- Dynamic controls
- File upload
- Drag and drop

## Project Structure
- `src/test/java` — test classes
- `pom.xml` — Maven dependencies

## Technologies Used
- IntelliJ IDEA
- ChromeDriver
- Maven
- GitHub

## How to Run Tests

```bash
mvn test
```

## Design Patterns
- Page Object Model (POM)
